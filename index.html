⚙️ How to install this extension inside Manager.io

  1. Host this file on a public URL (GitHub Pages, Netlify, etc.)
  2. Go to Manager.io → Settings → Extensions → New Extension
  3. Set Endpoint to your hosted URL
  4. Set Placement to /sales-invoices
  5. Save — open Sales Invoices tab and expand the extension panel at the bottom

⚠ This page requires the Manager.io manager-context postMessage to authenticate. It cannot load data when opened directly in a browser.
